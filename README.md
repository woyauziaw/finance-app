# 🚀 FINANCE APP v1.0 - CARA INSTALASI

1. Nyalakan **Apache** dan **MySQL** di Control Panel XAMPP Anda.
2. Akses **http://localhost/phpmyadmin/**.
3. Buat database baru bernama `finance_db`.
4. Klik tab **Import** dan pilih file `database.sql` yang berada di dalam folder ini, lalu klik **Go**.
5. Buka browser dan arahkan ke alamat web: **http://localhost/**.
